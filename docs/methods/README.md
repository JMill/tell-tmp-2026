# Methods Documentation

Paper-ready documentation for the four novel methods introduced by this work. Each method has its own markdown file with the formal definition, the rationale, the algorithmic specification, the evaluation strategy, and known limitations.

These docs are written to a quality where they can be cited from the praxis paper and from a standalone methods paper. They are NOT marketing copy. They are technical specifications.

## Methods

1. **[Information Vacuum Index (IVI)](ivi.md)** — quantifies the gap between public discourse volume and authoritative institutional response
2. **[Narrative Velocity Divergence (NVD)](nvd.md)** — flags when narratives accelerate faster than supporting evidence accumulates
3. **[Source Independence Graph](independence.md)** — distinguishes genuine multi-source corroboration from echo amplification
4. **[Sensemaking Quality Metrics (SQM)](sqm.md)** — evaluates sensemaking process against a hand-curated ground-truth timeline
